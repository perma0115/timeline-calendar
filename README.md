# タイムラインカレンダー（Notion埋め込み用）

Googleカレンダーを、Gluegent Apps Scheduler のような**横向きのタイムライン**で表示・編集し、Notionに埋め込むためのページです。

## できること

- 行＝カレンダー、列＝日、日の中を時間で区切った横向き表示（日／週／2週、幅は 小・中・大）
- 左側に月カレンダー（日付や週番号をクリックでその週へ）と、カレンダーの表示切替・色変更
- 空いている所をクリック／横にドラッグして予定を作成
- 予定をドラッグして日時を変更、別のカレンダーの行に落とすとカレンダーを移動、左右の端をドラッグして長さを変更
- 予定をクリックで詳細・編集・削除、「Googleカレンダーで開く」
- 祝日・土日の色分け、ダーク／ライト、5分ごとの自動更新
- 変更は直接Googleカレンダーに保存されるので、iPhoneのカレンダーやTimeTreeにもいつもどおり反映されます

## しくみ

```
Notion（埋め込み） → GitHub Pages（この画面） → GAS（あなたのGoogleアカウントで動く中継役） → Googleカレンダー
```

GASがあなたの権限でカレンダーを読み書きするので、Notionの中でGoogleのログイン画面を出す必要がありません。
GASを使えるのは「URLとキーを知っている人」だけです。

## 設定手順

### 1. GAS（中継役）を用意する（約5分）

1. https://script.google.com を開き、カレンダーを使っているGoogleアカウントで「新しいプロジェクト」を作成
2. 左上の「無題のプロジェクト」を「タイムラインカレンダー」などに変更
3. `コード.gs` の中身をすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の中身を貼り付けて保存（Ctrl+S）
4. 左側の「サービス」の **＋** → 「Google Calendar API」を選んで「追加」（IDは `Calendar` のまま）
5. 上部の関数の選択で **`setup`** を選び「実行」
   - 「承認が必要です」→「権限を確認」→ アカウントを選択
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「タイムラインカレンダー（安全ではないページ）に移動」→「許可」
     （自分で作ったスクリプトなので問題ありません）
6. 下の「実行ログ」に `キー: xxxxxxxx…` と表示されるので控えます
7. 右上の **「デプロイ」→「新しいデプロイ」** → 種類の選択（歯車）で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示された **ウェブアプリのURL**（`…/exec` で終わる）を控えます

### 2. GitHub Pages で公開する

1. GitHubで新しいリポジトリを作成（Public）
2. このフォルダの中身（`index.html`、`css`、`js`、`gas`、`README.md`、`.nojekyll`）をアップロード
3. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

> `gas` フォルダも公開されますが、キーは含まれていないので問題ありません。

### 3. 接続して Notion に埋め込む

1. 上のURLをブラウザで開くと接続設定が出るので、GASのURLとキーを入れて「接続する」
2. 表示された **「Notionに埋め込むURL」** をコピー
3. Notionで `/埋め込み`（`/embed`）→ URLを貼り付け →「リンクを埋め込む」
4. 埋め込みの下端をドラッグして高さを調整（今のNotionカレンダーの埋め込みは削除してOK）

> うまく表示されない場合は、埋め込みURLの `#` を `?` に変えて試してください。

## 使い方

| 操作 | 内容 |
| --- | --- |
| 空いている所をクリック | その時刻から1時間の予定を作成 |
| 空いている所を横にドラッグ | ドラッグした範囲の時間で予定を作成 |
| 予定をドラッグ | 日時を変更（別のカレンダーの行に落とすとカレンダーも移動） |
| 予定の左右の端をドラッグ | 開始・終了を変更 |
| 予定をクリック | 詳細・編集・削除 |
| 左の一覧のチェック | カレンダーの表示／非表示（右端の丸で色を変更） |
| キーボード `T` / `←` `→` / `N` | 今日へ / 前後へ / 新しい予定 |

- 繰り返し予定は「その回だけ」が変更されます（シリーズ全体はGoogleカレンダーで変更してください）
- 閲覧のみのカレンダー（祝日など）は鍵マーク付きで、編集できません
- 表示する時間帯（初期値 7〜20時）、週の始まり、テーマ、カレンダーの表示名は右上の設定ボタンから変更できます
- 表示時間の外にある予定（早朝・深夜）は、その日の左端／右端に寄せて表示されます

## 注意

- **埋め込みURLにはキーが入っています。** 知られると予定を読み書きできてしまうので、他の人に共有しないでください。
  漏れたときは GAS で `resetKey` を実行し、新しいキーで設定し直してください。
- GASのコードを変更したときは「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョンを「新バージョン」→「デプロイ」（URLは変わりません）。
- TimeTreeで直接作った予定はGoogleカレンダーに入らないため、ここにも表示されません。

## 試しに動かしたいとき

公開したURLの末尾に `#demo=1` を付けるか、接続設定で「デモデータで試す」を押すと、ダミーの予定で操作を試せます（変更は保存されません）。
